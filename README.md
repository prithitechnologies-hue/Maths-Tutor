# Maths Tutor

A bilingual (Tamil/English) maths practice and mock-exam app for school students, built with Flutter.

**Package:** `com.prithi.maths_tutor`
**Platform:** Android (Google Play)

## About

Maths Tutor helps students practice for Olympiad-style exams and school-syllabus maths through timed mock papers, topic-wise drills, and a gamified progress system — fully available in both Tamil and English.

## Features

- **32 SOF IMO-style mock papers** (1,080 questions), fully bilingual
- **Scholarship mock exams** — TN State Scholarship pattern (Class 7 & 8) and NMMS SAT-Mathematics pattern (Class 8), 90 questions per paper
- **IGCSE Class 8 track** — 77-question practice bank across 8 topics, plus a 90-question bilingual mock paper
- **Question Paper Generator** — dynamically generated practice mirroring the IG Maths Book 1/Book 2 course structure, including Grade 8 worksheet-style practice
- **Gamification** — XP, levels, badges, and daily streak tracking
- **Global leaderboard** — powered by Firebase Firestore, ranked by accuracy and speed
- **Weak topic detection** to guide what to practice next
- **Handwriting scratchpad** — Google ML Kit-powered handwriting recognition, plus a built-in calculator
- **Language toggle** — switch between Tamil and English at any time, including in exams
- **Onboarding flow** — language and class selection on first launch
- **Pro upgrade** — removes ads and unlocks premium papers (e.g. NMMS), via in-app entitlement and Google Play Billing

## Tech Stack

- **Flutter / Dart**
- **Firebase** — Firestore (leaderboard), used across the Prithi Technologies app suite
- **Google ML Kit** — on-device handwriting recognition
- **Google AdMob** — advertising (free tier)
- **SharedPreferences** — local progress, streaks, and entitlement storage
